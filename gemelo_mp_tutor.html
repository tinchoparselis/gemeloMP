Configuración opcional para una versión con IA

El HTML funciona sin conexión. Para recibir respuestas generadas por un modelo basado en el corpus de MP, necesitás un backend propio con HTTPS, autenticación, protección contra abuso y control de costos. Nunca coloques una clave de API en el HTML distribuido a estudiantes.

Contrato propuesto: POST {topicId,phase,question,answer,previousAnswer,criteria}. Devuelve {feedback,followUp?}. La conexión no está configurada en esta versión.
